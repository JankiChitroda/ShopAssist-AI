# ShopAssist AI
**AI-Powered Multi-Agent E-Commerce Customer Support Platform**

ShopAssist AI is an intelligent customer support platform built specifically for e-commerce. It bridges the gap between automated RAG pipelines and enterprise reliability, transforming manual support into a streamlined, policy-compliant, and scalable workflow.

---

## Key Capabilities & Workflow
1. **Understand** – AI analyzes customer queries and checks order history.
2. **Classify** – Machine learning determines issue type and intent.
3. **Retrieve** – AI accesses the knowledge base using RAG for relevant store policies.
4. **Resolve** – LLMs draft solutions while validation guardrails ensure accuracy.
5. **Escalate** – Complex cases are seamlessly transferred to human specialists via Jira/Email service stubs.

---

## Technology Stack
* **AI & ML:** LangChain, LangGraph, Sentence Transformers, FAISS, Large Language Models, Vector Embeddings
* **Backend:** Python, Flask, Pydantic, REST APIs
* **Database & Storage:** SQLite, PostgreSQL, Vector Store, Knowledge Base
* **Frontend:** HTML, Tailwind CSS, Jinja2 Templates
* **Integrations:** Order Service, Refund Service, Jira, SMTP Email

---

## Core Modules
* **Authentication Module:** Secures user registration, login, and JWT-based session authentication.
* **Knowledge Base & RAG Engine:** Stores store policies and retrieves precise context for queries.
* **Validation & Confidence Engine:** Evaluates query clarity and verifies policy compliance before resolution.
* **Enterprise & Persistence Layer:** Handles ticket escalations, email notifications, and support record storage.
